Three steps to the first night.

No server setup. The host phone is the server.

1 Install

Download the APK on the Android phone that will host the game. Allow install from this source when Android asks.

2 Host

Put everyone on the same Wi-Fi. Open Noctwolf and start a table.

3 Join

Players join from the Android app or from a browser on the same network.
